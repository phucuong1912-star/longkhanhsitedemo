Có thể dùng repository Actions secrets cùng tên nếu không dùng environment

environment này về prod nếu muốn ngăn nhánh khác dùng các secrets này.

Không cần thêm biến cho VPS hiện tại. Khi đổi server có thể cấu hình variables:
  PROD_SSH_HOST, PROD_SSH_PORT, PROD_SSH_USER, PROD_WEB_ROOT, PROD_SITE_URL.
PROD_SITE_URL là HTTPS origin, không thêm dấu / cuối. Host mới phải có WP-CLI,
rsync, PHP đúng phiên bản, WordPress đã khởi tạo và marker .lk-prod-deploy
trong web root chứa đúng PROD_SITE_URL ở dòng đầu.

Lần đầu đưa nhánh lên GitHub
  git push -u origin prod

Các lần cập nhật code tiếp theo
Commit thay đổi code đã kiểm tra trên master, sau đó:
  git switch prod
  git merge master
  git push origin prod

GitHub Actions sẽ:
1. Kiểm tra nhánh, đường dẫn cụ thể, host key đã ghim và phiên bản WordPress.
2. Chuyển source vào thư mục tạm, kiểm tra thư viện React/Elementor và PHP
   của child theme/plugin Long Khánh.
3. Sao lưu database và code cũ vào /root/longkhanh-prod-backups/ (ngoài web root).
4. Cập nhật code, tạo lại CSS Elementor, xóa cache và kiểm tra HTTP trang chủ.

Các lần push code giữ lại
- wp-config.php, .htaccess, .user.ini và chứng chỉ/cấu hình server.
- Toàn bộ wp-content/uploads, cache/runtime và dữ liệu người dùng.
- CSS ListingPro sinh từ cấu hình database: assets/css/dynamic-css.css.
- Database, bài viết, review, tài khoản và bố cục Elementor đang có trên prod.
- File vendor của WordPress và Elementor vẫn được deploy đầy đủ.

Không dùng --delete khi rsync. File runtime không bị xóa bởi code push; nếu
xóa/đổi tên file code trong repository, cần xử lý file cũ có chủ đích khi deploy.
Mỗi lần deploy có bản sao trước sửa để khôi phục nếu cần.

Nội dung Elementor và ảnh
Đổi chữ, bố cục hoặc ảnh bằng Elementor ở local là thay đổi database, không
tự đi theo git push. Chuyển đúng trang/template và ảnh liên quan, thay URL
theo môi trường rồi tạo lại CSS. Không import đè toàn bộ database local lên
production đang nhận bài/review mới. Đợt import toàn database từ local vào
VPS hiện tại là bước chuyển site ban đầu, tách khỏi workflow push code.

Thông tin xác thực
- Khóa riêng chỉ nằm trên máy này và GitHub Secrets nếu chủ website cho phép.
- Có thể thu hồi bằng cách xóa dòng public key có ghi longkhanh-prod-deploy
  trong /root/.ssh/authorized_keys và xóa secret GitHub tương ứng.
- Không commit wp-config.php của VPS, khóa riêng, file SQL hay mật khẩu.
- File backup chứa dữ liệu/config được giữ trong thư mục root riêng trên VPS.
